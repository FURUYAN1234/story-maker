# Story Maker v5.5.7

## Changes / 更新内容

- [ci] Install the locked MCP dependencies during the main npm install so that a fresh checkout can build and run the tests in GitHub Actions. / 本体のnpmインストール時にMCPの依存関係もロックファイルから入れ、GitHub Actionsのクリーン環境でビルド・テストできるようにしました。
- [windows] Restore local Windows startup when the MCP dependencies are missing. / MCPの依存関係が不足している場合に、Windowsの起動バッチで補えるようにしました。
- [manga-preview] Show each panel’s action and dialogue in a readable preview and preserve the original handoff script when copying. / 複数ページ台本ではコマごとの状況と台詞を読みやすく表示し、コピー時は漫画アプリ連携用の配置情報も渡します。
