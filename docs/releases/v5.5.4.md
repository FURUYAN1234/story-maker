# Story Maker v5.5.4

## Changes / 更新内容

- [manga] Generate a 4–8-panel scenario and character notes through MCP, then hand the selected output to Super FURU AI 4-koma System. / MCPで4〜8コマの漫画台本と人物設定を作り、選んだ内容をSuper FURU AI 4-koma Systemへ渡せます。
- [connection] Added a verified local MCP connection with a single stop control at the top of the app. / ローカルMCP接続に対応し、接続中の停止操作を画面上部の一つのボタンにまとめました。
- [manuals] The app offers its production skill, MCP setup guide, operation manual, and API setup manual in the upper toolbar. / 画面上部から制作スキル、MCP導入ガイド、操作マニュアル、API設定マニュアルを開けます。
- [launcher] Launch-MCP.cmd starts and stops the service and checks for app updates on Windows. / Windows用のLaunch-MCP.cmdからサーバーの起動・停止と更新の確認ができます。
