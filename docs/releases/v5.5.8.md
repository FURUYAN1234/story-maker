# Story Maker v5.5.8

## English

### What's New

- [windows-launch] Fixed Windows ZIP startup so Story Maker opens with Node.js and npm using the manga compatibility files included in the ZIP. The launcher checks those files before starting the app.

## 日本語

### 更新内容

- [windows-launch] Windows配布ZIPを展開して起動したときに、漫画アプリの開発用ソースを要求して停止する不具合を修正しました。Node.jsとnpmが入っていれば、同梱の漫画連携ファイルを照合してからアプリを起動します。
