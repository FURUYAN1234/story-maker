# Story Maker v5.4.7

## Changes / 更新内容

- [structure] Adapt story structure to the selected length, form and ending across generation, review and revision. / 生成・講評・改稿で、尺・形式・指定された結末に合わせて物語の構成を調整します。
- [review] Keep editorial instructions separate from drafting targets and report the selected model and actual waiting state. / 講評に本文生成用の指示が混ざる不具合を修正し、選択モデルと実際の待機状態を表示します。
- [length] Check the public minimum on body text, repair short initial manuscripts and reject undersized revisions even when scored higher. / 本文で字数下限を確認し、短い初稿を補完します。高得点でも下限未満の改稿は採用しません。
- [import] Enable the editorial controls after importing a manuscript. / 本文を取り込んだ後に、講評・ブラッシュアップの操作欄を使えるよう修正しました。
- [manga] Align supported scene directions with the current Super FURU AI 4-koma System contract. / Super FURU AI 4-koma Systemの現行仕様に合わせ、対応する演技指示を同期しました。
