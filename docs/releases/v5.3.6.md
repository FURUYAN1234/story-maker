# Story Maker v5.3.6

## English

### What's New
- [api-key] API keys are retained only in memory for the current tab.
- [url-proxy] URL imports no longer use third-party public proxy services.
- [trust] Added public privacy, licensing, and CI materials.

### Verification
- [tests] Unit tests and the production build passed before release.
- [api-smoke] OpenAI and Gemini were each exercised from the local app without reading key values.

## 日本語

### 更新内容
- [api-key] APIキーは現在のタブのメモリ内だけに保持します。
- [url-proxy] URL素材の読み込みで第三者の公開プロキシを使用しません。
- [trust] 公開用のプライバシー、ライセンス、CI資料を追加しました。

### 検証
- [tests] リリース前にユニットテストと本番ビルドが成功しました。
- [api-smoke] APIキーの値を読み取らず、ローカルアプリからOpenAIとGeminiをそれぞれ実行しました。
