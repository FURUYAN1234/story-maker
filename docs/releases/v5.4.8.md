# Story Maker v5.4.8

## Changes / 更新内容

- [manga-format] Choose 4–8 panels from story content for the manga app’s default free layout and preserve PageComposition through cleanup and revision. / 漫画アプリ既定の自由配置に合わせて内容から4〜8コマを選び、最終整形・改稿でもPageCompositionを保持します。
- [character-handoff] A user-declared same-sheets checkbox selects scenario-only output; otherwise generate separate STEP1 character settings after the final scenario, with consistent names, appearance, clothing and age variants in one entry. No automatic image identity detection is performed. / 同一シートの自己申告チェック時は台本のみ、未チェック時は最終台本の後にSTEP1用人物設定を別途生成します。名前・外見・服装を揃え、同一人物の年齢違いを一項目にまとめます。画像の同一性は自動判定しません。
- [copy] Provide full copy and separate STEP1 and scenario copy; paste the scenario into STEP2, then run STEP3. / 全体コピーとSTEP1用・台本用の個別コピーを用意し、台本はSTEP2へ貼ってからSTEP3へ進めます。
- [compatibility] Check current source contracts and the real manga parser during development, tests, builds and the shared manga release route. / 開発・テスト・ビルドと漫画アプリの共通公開経路で、現行仕様と実際の漫画パーサーを照合します。
