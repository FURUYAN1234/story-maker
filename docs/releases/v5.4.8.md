# Story Maker v5.4.8

## Changes / 更新内容

- [manga-format] Choose 4–8 panels from story content for the manga app’s default free layout and preserve PageComposition through cleanup and revision. / 漫画アプリ既定の自由配置に合わせて内容から4〜8コマを選び、最終整形・改稿でもPageCompositionを保持します。
- [character-handoff] Imported character sheets keep scenario-only output. Without an imported sheet, add separate STEP1 character settings and full/scenario/character copies. Images are not automatically compared between apps. / キャラシートを実際に取り込んだ場合は台本のみを出力し、未取り込み時はSTEP1人物設定と全文・台本・人物設定の個別コピーを追加します。両アプリの画像は自動照合しません。
- [copy] Provide full copy and separate STEP1 and scenario copy; paste the scenario into STEP2, then run STEP3. / 全体コピーとSTEP1用・台本用の個別コピーを用意し、台本はSTEP2へ貼ってからSTEP3へ進めます。
- [compatibility] Check current source contracts and the real manga parser during development, tests, builds and the shared manga release route. / 開発・テスト・ビルドと漫画アプリの共通公開経路で、現行仕様と実際の漫画パーサーを照合します。

- [app-links] Use the related-app buttons below the top controls to open Character Maker or the manga app in a separate tab. Each button explains where to use the saved sheet or copied scenario. / 上部の操作欄の下にある連携アプリボタンから、キャラクターメーカー・漫画アプリを別タブで開けます。保存したシートやコピーした台本の使い先も、各ボタンの説明で案内します。
