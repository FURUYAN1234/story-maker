# Story Maker v5.4.4

## English

### What's New

- [vision] Migrated fixed single-image, multiple-image and text-helper routes to maintained Sol/Terra/Luna models with compatible completion parameters.
- [models] Removed retiring GPT-4 choices and fallback routes; retained the existing story, camera, acting and scenario contracts. Incomplete analysis output stops before adoption.
- [selection] Single-image and multiple-image analysis now follow the selected OpenAI model and report the attempted and adopted model.
- [import] Unified the character-import JSON object contract and reject entries without character information. Existing array responses remain supported.
- [nano-contract] Synchronized Nano's current wardrobe-continuity and drawing rules; the deployment gate checks the assembled four-panel format.

## 日本語

### 更新内容

- [vision] 固定の単一画像・複数画像解析と補助文章処理を現行のSol/Terra/Lunaへ移行し、互換のある出力上限を設定しました。
- [models] 終了予定のGPT-4系を選択肢とフォールバックから除外しました。物語・カメラ・演技・シナリオの契約は維持し、解析応答が未完了なら採用せず停止します。
- [selection] 単一画像・複数画像の解析にもOpenAIの選択モデルを反映し、試行・採用モデルを表示します。
- [import] キャラクター取り込みのJSONオブジェクト形式を共通化し、人物情報のない項目を拒否します。従来の配列形式も読み込めます。
- [nano-contract] Nanoの現行の衣装継続・描画ルールを同期し、公開前に実際に組み立てた4コマ書式を照合します。
