# Story Maker v5.5.6

## Changes / 更新内容

- [manga-modes] Choose a one-page manga or a multi-page manga. Multi-page scripts support a fixed or automatically selected length, with 4–8 panels per story page. / 「1ページ漫画」と「複数ページ漫画」を選べます。複数ページでは本文を各4〜8コマとし、ページ数を固定するか、題材に合わせて自動で決めます。
- [mcp-book] The MCP tool `story_generate_manga_script` returns page-by-page scripts and a shared cast. Each page uses the preceding page's ending and the common cast for continuity. / MCPの `story_generate_manga_script` でページごとの台本と共通の人物設定を取得できます。前ページの最後のコマと共通の人物設定を引き継いで、本文を順に作ります。
- [cast-check] Remove unsupported cast entries before rechecking the required cast. / 台本に根拠のない人物設定が紛れ込んだ場合は、その項目を外して必要な人物設定を再検査します。
- [manuals] The operating manual, API guide, and MCP guide cover the current version. / 操作マニュアル、API設定ガイド、MCP導入ガイドを現行版に合わせました。
