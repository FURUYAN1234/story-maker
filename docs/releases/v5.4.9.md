# Story Maker v5.4.9

## Changes / 更新内容

- [disconnect] Add a shared “Force disconnect AI communication” control for thought waiting, streamed generation, editorial/brushup, image analysis and character helpers. / 思考待ち・ストリーム生成・講評と改稿・画像解析・人物設定補助に共通の「緊急停止（AI通信を切断）」を追加します。
- [cancellation] Abort browser requests, suppress delayed responses and block subsequent automatic continuation, retries and model fallback until an explicit new run. / ブラウザーの通信を中断し、遅延応答を破棄。利用者が再実行するまで後続の自動継続・再試行・モデル切替を止めます。
- [preservation] Preserve settings and the in-memory API key. Standard generation restores the previous Output; brushup preserves its source manuscript. / 設定とメモリー内のAPIキーを保持。通常生成は生成前のOutput、ブラッシュアップは元原稿を保持します。
- [guides] Update bilingual instructions and Japanese PDF guides. Provider-side processing or billing cancellation is not guaranteed. / 英日説明と日本語PDFを更新。API提供元での処理・課金停止は保証しません。
