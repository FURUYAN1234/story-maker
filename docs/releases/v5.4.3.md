# Story Maker v5.4.3

## English

### What's New

- [scenario] Updated four-panel scenario integration to current Nano STEP2 rules: VisualEvidence, dialogue-matched BalloonLayout, intentional silence, camera projection, acting, props and wardrobe.
- [completion] Validates assembled and revised scenarios, accepts explicit silent endings, preserves Topic and keeps the received draft when validation fails.
- [sync] The build check now compares shared Nano rule definitions and automatic drawing styles as well as the output format.

## 日本語

### 更新内容

- [scenario] 4コマシナリオ連携を現行Nano STEP2ルールへ更新。VisualEvidence、台詞と一致するBalloonLayout、意図した無言、カメラ投影、身体演技、小道具と服装を反映します。
- [completion] 継続応答を結合したシナリオと改稿の形式を検証し、明示された無言の結末を許可してTopicを保持します。検証エラー時も受信本文を残します。
- [sync] ビルド時の同期チェックで、出力形式に加えてNanoの共通ルール定義と自動選択する画風を照合します。
