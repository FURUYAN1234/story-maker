Story Maker v5.5.8のMCP導入

Windowsで起動する

  1. 公式GitHubリポジトリのソースZIPを展開し、Node.js 22.16以降を用意します。
  2. Launch-MCP.cmd を開き、「Start MCP and open the application」を選びます。ウィンドウを切り替えるときは、作業を保存してから停止してください。
  3. 画面の「MCP接続」から接続できます。Codexからは実行チャットの内蔵ブラウザーで story_connection が返す一時URLを開くと自動接続します。

Codexに登録する

展開先の絶対パスを指定します。起動バッチで新版に切り替えた後も、この登録先から新しい管理版を選びます。

codex mcp add story-maker -- node "C:\path\to\story-maker\Launch-Codex-MCP.mjs"

通常のアプリ画面でAPIを接続し、story_capabilities の接続状態と providerReady を確認します。APIキーはチャットや設定ファイルの引数に入れません。

生成して次のアプリへ渡す

story_generate_manga_script で開始し、story_job_get で完了と成果物を確認します。停止は story_job_cancel で依頼できます。

返った人物設定と台本は、採用後に漫画のSTEP1とSTEP2へ渡せます。

複数ページは input.brief に加え、input.book を指定します。各4コマの本文2ページにする例です。

{"brief":"作品の題材と制作条件","book":{"mode":"fixed","pagePanelCounts":[4,4]}}

{"mode":"auto"} で作品に合うページ数を選べます。book を省くと従来の1ページです。複数ページは book.pages の pageNumber 順に採用台本を渡し、共通の人物設定は characters から取得します。

制作スキルZIPを取得。展開した story-maker-manga-script フォルダーをCodexのスキル用フォルダーに配置し、SKILL.md が見えることを確認します。

更新する

起動バッチの「Check for an application update」または「Update the application」を使います。更新候補は別の場所に展開・ビルドされ、成功した版だけが次回起動の対象になります。
