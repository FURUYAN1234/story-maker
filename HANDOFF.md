### Required Pipeline Coverage
Do not rely on a tail-only cleanup.

Use the canonical classifier in all of these places:
- `He(text)`: strip chapter-control lines at the current chapter tail before save.
- `le(text)`: remove standalone chapter-control lines anywhere in visible combined manuscript text.
- `ot(text, opts)`: reject any chapter body that still contains standalone chapter-control artifact lines before it is appended to `longNovel.chapters`.
- Final-completed manuscript assembly: after all chapters are joined and before showing completed output / appending footer, run a whole-manuscript guard. If any chapter-control artifact remains between chapters, do not treat completion as accepted.
- Any `.txt` save/copy path should receive the already-clean manuscript, not a separate unclean source.

The final whole-manuscript guard is essential because the v4.1.8 failure was between chapters, not at the current tail after completion.

### Suggested Implementation Shape
Prefer a single helper group rather than separate v4.1.9 one-off wrappers:

```js
const smChapterControlArtifactLineRe = /.../i;

function smNormalizeControlLine(line) {
  return String(line || "")
    .trim()
    .replace(/^[>＞\s]+/, "")
    .replace(/^[<＜【\[(（]+/, "")
    .replace(/[>＞】\])）]+$/, "")
    .trim();
}

function smLooksLikeChapterControlArtifactLine(line) {
  const raw = String(line || "").trim();
  const s = smNormalizeControlLine(raw);
  if (!s) return false;
  if (smLooksLikeChapterReferenceProseV417 && smLooksLikeChapterReferenceProseV417(raw)) return false;
  if (raw.length > 120 && /[。！？!?」』]$/.test(raw)) return false;
  return smChapterControlArtifactLineRe.test(s);
}

function smStripChapterControlArtifactLines(text) {
  return String(text || "")
    .replace(/\r\n/g, "\n")
    .replace(/\r/g, "\n")
    .split("\n")
    .filter(line => !smLooksLikeChapterControlArtifactLine(line))
    .join("\n")
    .replace(/\n{3,}/g, "\n\n")
    .trim();
}
```

This is only a sketch. The actual regex must be tested against all old failure forms and preservation cases.
